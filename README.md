# ScrapeFun Client for Windows

> 最后更新：2026 年 7 月 26 日

ScrapeFun Client 是用于连接现有 ScrapeFun Server 的 Windows 桌面客户端，不会在本机启动服务端。

## 下载与安装

从 [Releases](https://github.com/HaoweiLi97/scrapefun-client-windows/releases/latest) 下载与你的处理器架构匹配的 `setup.exe`，双击完成安装。

当前发布以 `x64` 为主；其他架构是否可用，以下载文件名为准。

## 连接服务器

首次打开客户端后，填写 ScrapeFun Server 地址，例如：

```text
http://192.168.1.10:8096
```

服务器可以来自 Docker、macOS Server 或 Windows Server。

## 更新

有新版本时，从 Releases 下载并运行新版安装程序，服务器地址等客户端配置会保留。
